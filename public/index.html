A small, inspectable engine for turning structured ideas into timed visual explanations.

Distinct chapters; actual duration follows narration. Boxes appear as the spoken words arrive.

Reviews each scene's rendered thumbnail with a second AI model and repairs it once if flagged — overlap, clipped text, or a weak visual metaphor. Adds cost and latency per scene.

ElevenLabs provides natural speech with word alignment. Some library voices require a paid plan. Kokoro runs a local neural voice with native word timings (needs KOKORO_PYTHON set to a Python with kokoro-mlx). Python robot voice remains an optional local mode.
