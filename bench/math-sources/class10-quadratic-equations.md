# Quadratic equations

A quadratic equation has the form a x squared plus b x plus c equals 0, where a is not zero. Its graph is a parabola.

The solutions, called roots, are the points where the parabola crosses the x-axis. The quadratic formula gives them: x equals minus b plus or minus the square root of b squared minus 4 a c, all divided by 2 a.

The discriminant, D equals b squared minus 4 a c, tells how many real roots exist. If D is greater than zero there are two real roots; if D equals zero there is one; if D is less than zero there are none.

Example: x squared minus 5 x plus 6 equals 0 has a equals 1, b equals minus 5, c equals 6. Then D equals 25 minus 24 equals 1, so there are two roots: x equals 3 and x equals 2.
