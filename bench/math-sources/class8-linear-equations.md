# Solving a linear equation in one variable

An equation states that two expressions are equal. A linear equation in one variable has the variable to the first power only, for example 2x + 3 = 11.

To solve it, undo the operations in reverse order while keeping the equation balanced: whatever you do to one side you must also do to the other side.

Subtract 3 from both sides: 2x = 8. Then divide both sides by 2: x = 4.

Check the answer by substituting back: 2 times 4 plus 3 equals 11, which is true. The solution is the value that makes both sides equal.
