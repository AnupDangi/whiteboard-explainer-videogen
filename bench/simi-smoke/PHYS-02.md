# Projectile motion separates horizontal and vertical motion

[S1] Ignoring air, horizontal velocity stays constant because no horizontal force acts. [S2] Vertical velocity changes by g downward (~9.8 m/s2), so the object rises then falls symmetrically. [S3] The combined path is a parabola; horizontal and vertical motions proceed independently. [S4] Range grows with launch speed and depends on angle; 45 degrees maximizes range on flat ground.
