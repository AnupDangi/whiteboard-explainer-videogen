# Recursion and the call stack

[S1] Recursion solves a problem by calling the same function on a smaller input. [S2] Each call pushes a frame on the call stack; the base case stops with a direct answer. [S3] Returns then unwind: each frame completes using the smaller result (e.g. factorial n! = n * (n-1)!). [S4] Missing base case recurses forever until stack overflow.
