# Equivalent fractions represent the same quantity

[S1] A fraction names equal parts of a whole: the denominator counts how many parts make the whole, the numerator counts taken parts. [S2] Multiplying numerator and denominator by the same nonzero number re-cuts each part into the same number of smaller pieces, so the covered amount is unchanged. [S3] Example: 1/2 equals 2/4 because cutting each half into 2 pieces gives 2 quarters covering the same area.
