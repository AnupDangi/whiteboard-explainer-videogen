# Completing the square

Completing the square rewrites a quadratic expression x^2 + bx + c as a perfect square plus a constant. A perfect square trinomial has the form (x + h)^2 = x^2 + 2hx + h^2. The middle coefficient is twice h, so h is half of b, and the constant needed to complete the square is h^2, which is (b/2)^2.

To solve x^2 + 6x + 5 = 0 by completing the square, first move the constant: x^2 + 6x = -5. Half of 6 is 3, and 3 squared is 9. Add 9 to both sides to keep the equation balanced: x^2 + 6x + 9 = 4. The left side is now (x + 3)^2, so (x + 3)^2 = 4. Taking the square root of both sides gives x + 3 = 2 or x + 3 = -2. Therefore x = -1 or x = -5.

The method works because adding the same number to both sides never changes the solutions. Geometrically, x^2 + 6x is a square of side x with two rectangles of width 3 attached; the missing corner is a 3 by 3 square of area 9, which completes the larger square of side x + 3.

When the coefficient of x^2 is not 1, divide the whole equation by that coefficient first. Completing the square is also how the quadratic formula is derived: applying it to ax^2 + bx + c = 0 gives x = (-b ± sqrt(b^2 - 4ac)) / (2a).
