# Director failure modes

- Omitted required concept -> `Director omitted concept` throw; add node.
- Invented asset -> throw; pick from candidateAssets only.
- Changed narration/beat -> throw; direction carries no text edits.
- Bad anchor -> canonicalize or degrade to center with diagnostic.
- Label-only hero (structural archetype) -> choose semantic composition.
- All-box gaming -> not a failure by itself; minimality governs. Forced
  variety is removed; unjustified decoration is the failure.
