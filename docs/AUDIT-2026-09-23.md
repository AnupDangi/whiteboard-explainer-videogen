## 2. Bugs found by reading the code (all fixed)

1. Edges were drawn at t=0 with no arrowheads, and their anchors were ignored.
2. Icon labels were dropped at rungs 2 and 3.
3. All of an element's paths were revealed at once, and text popped in.
4. The fill tail ran outside the 2-server scheduler. This was the live EMI `concurrency` failure.
5. Narration was about 3 s per scene, followed by about 20 s of silence. This was fixed at the source by S4 word
   budgets.
6. Title size was 35 px, and there was no scene transition.
7. Occupancy scaling spread elements apart without growing them.
8. The 4-word *label* rule was applied to titles. This caused the live `why_attention` failure. The spec only limits
   labels, and reference titles run to 6 words.
9. The planner accepted invented mention ids, which silently degraded to "reveal at scene start".
10. `circleLayout` could push spokes off the canvas.

## 4. Icons: Iconify vs Streamline

Both, in effect:
- **Streamline** artwork: the free CC BY 4.0 duotone sets, whose outline + fill structure maps directly onto
  Lamina's black outline + one pastel fill.
- **Delivered through Iconify's local JSON**: zero network, 462 MB already on disk.

Rejected options:
- MIT emoji sets: the style is too far from the reference.
- Live Streamline API search: slow, and the free tier gives about 50% coverage (prior spike).
- LLM-generated SVG at run time: the spec forbids it.

The gap strategy:
- concepts with no good icon become labelled boxes, since a wrong icon is worse than a box (live runs showed a flag
  used for a triangle and a star used for the number 5; both are now guarded against);
- geometry and quantities use code-drawn primitives;
- the offline asset factory (rung 5) is the documented next step.

## 6. Recommended approach

This is the same approach the evidence supports: keep the Claude hypothesis architecture.
- The LLM emits a constrained DSL; code draws.
- Narration is written first, and audio is the master clock.
- One house style comes from a normalized Streamline catalog plus code-drawn math primitives.
