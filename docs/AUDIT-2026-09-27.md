## 3. Pipeline map

```
lessonCli / one-shot-video
  S1   intake            plan/sourceIntake.ts -> plan/intake/registry.ts -> one SourceExtractor per format
       bundle + ranking  plan/sourceBundle.ts        optional RAG index: plan/ragSidecar.ts (gated, §5)
  S1b  syllabus          plan/hierarchical.ts        long sources: span excerpts, no offsets
  S2   concept graph     plan/stages.ts              module mode: relations only, concepts from syllabus
  S3   teaching plan     plan/stages.ts + plan/contracts.ts   model drafts, code derives contracts
  S4   narration         plan/stages.ts writeScript  [[id|phrase]] markers, 4-7 per scene
  S5   TTS + alignment   pipeline/sceneAudio.ts      shared by lesson preparation and the live run
  S6   board planner     planner/registry.ts -> planner/board.ts (default) | planner/plan.ts
  S7-10 visual chain     pipeline/visualChain.ts     resolve -> layout -> timeline -> gates -> final frame
  S11  encode            export/*                    module clips, chapters, captions
  S12  gates + judge     validation/gates.ts, shared/evaluation.ts, harness/*
```

Configuration lives in three places:
- `config.ts`: lesson durations and cost caps, scene gap, provider timeout, RAG threshold, relation arrows.
- `style.ts`: visual tokens, occupancy band, title band, readability floor.
- `plan/intake/limits.ts`: intake sizes and timeouts.

Stage and prompt versions are part of each artifact's cache key, so changing a rule never replays an old
result.

## 4. Document intake (PDF / DOCX / PPTX / HTML / text)

Every reader returns canonical text with extractor-authored location ranges, a title, figures and
warnings. `finalizeSourceDoc` turns that into the `SourceDoc` every stage reads. `SourceDoc.intake` records the
reader id, its version and its warnings; the warnings also appear as soft failures on the S1 stage record.

| Reader | Selection | Behaviour |
|---|---|---|
| `pdf-poppler` (default) | `HYPOTHESIS_PDF_EXTRACTOR=poppler` | `pdftotext` in reading order: block breaks, words hyphenated across lines joined (`HYPOTHESIS_PDF_TEXT_MODE=raw` keeps stream order). Headers, footers and page numbers repeated at page edges on ≥40 % of pages are removed. Pages without text are reported. Title from `pdfinfo` unless it is a placeholder. Images via one `pdfimages -p` pass. |
| `pdf-docling` | `=docling` (fails visibly if unavailable) or `=auto` (falls back to poppler with an `extractor-fallback` warning) | `parse-engine/convert.py` items → located blocks: headings, lists, formulas as `$$`, tables as Markdown, figure captions; page headers/footers dropped; picture crops become figures. |
| `docx-ooxml` | `.docx` | Content controls kept; field codes and deleted revisions dropped; runs joined without spaces; outline-level headings; inline/display math; core-properties title. Over 100 media → warning and cap. |
| `pptx-ooxml` | `.pptx` | `presentation.xml` order; grouped shapes; hidden slides skipped (warning); title from core properties or the title placeholder. |
| `html-cheerio` | URLs / `.html` | Each block once (no nested repeats); h1–h6, lists, tables, blockquote, pre, dt/dd, prose-only divs; charset from header or `<meta>`. |
| `text-utf8` | `.txt`, `.md`, `.json` | As is (JSON pretty-printed). |

The same rules apply to every reader:
- **Canonical text.** NFC, ligatures expanded, soft hyphens and zero-width characters removed, before any
  location is recorded.
- **Titles.** Never a generated `Page 1` / `Slide 1`. The order is metadata, then a real heading, then the
  file name.
- **One path for files and URLs.** URL PDFs are no longer page-wrapped twice. URLs have a 180 s total deadline.
- **Spans.** A span closes at a sentence end after 1,500 characters and never crosses a page or document.
  Figure references are singular and case-sensitive ("the tables below" is prose).
- **Anchoring.** Folds accents, ligatures and invisible characters. Matches a compound word split at a line
  end (`well-\nknown`) with its hyphen. The stored quote is always the exact source substring.
- **RAG mapping.** A retrieved chunk maps to the longest run of span sentences (≥ 40 chars) it reproduces.

Tests run on committed synthetic fixtures (`__tests__/fixtures/intake/`, regenerated by
`make_fixtures.py`). The PDF tests skip when `pdftotext` is not installed.

## 5. How to extend

**A document reader.** Implement `SourceExtractor` (`plan/intake/types.ts`), then call
`registerSourceExtractor(reader)`. Return canonical text: use `joinBlocks`, which canonicalizes each block and
records its range. Bump `version` whenever output changes, because it is part of the S1 cache key.

**A scene template.**
1. Add a spec to `templates/catalog.ts`: slots, `requiredSlots`, recipe.
2. Add its geometry function to `TEMPLATES` in `templates/definitions.ts`. The compiler rejects a missing
   function.
3. Add a regression test that changes topic and values while keeping the template fixed.

The TemplateId type, zod enum, prompt slot table, recipes and typed-board gate all derive from the spec.

**An S6 planner.** Implement `ScenePlanner` in `planner/registry.ts`: prompt, plan, versions, and whether scenes
are independent. Call `registerScenePlanner`, then select it with `--scene-planner=<id>`. Scene calibration
measures the same registry (default `board-v2`).

**A model provider.** Implement `ModelClient` (`llm/modelClient.ts`): `chat(request)`, plus `pricing(model)` if
the provider publishes prices. Pass it as `client` to `structuredCall`. An OpenAI-compatible endpoint needs only
`OPENROUTER_BASE_URL`.

**Arrow wording.** Edit `RELATION_ARROWS` in `config.ts`, then bump `BOARD_STAGE_VERSION`.

**RAG gating.** With `RAG_ENGINE=on`, the index is skipped for a single text-only source under
`PIPELINE.ragMinSourceChars`. The skip is recorded as `skipReason`. `RAG_ENGINE=always` indexes everything.

## 7. Known limits and deferred work

- **Live runs are unmeasured.** This container gets HTTP 403 from `openrouter.ai` and `huggingface.co` and has
  no ffmpeg. No generated lesson, cost, pass rate or visual quality was measured here. See §8.
- **Docling end-to-end is unmeasured.** There is no `parse-engine/.venv` here. The item-to-block mapping is
  tested with synthetic items.
- **One shared Python worker helper: deferred.** The alignment pool (`shared/alignment/align.ts`) and the voice
  pool (`voice-engine/src/python-bridge.ts`) live in separately built packages. Merging them needs a workspace
  package.
- **`baseline:verify` fails, and the failure predates this work.** `fixtures/attentionScenes.ts` differs from
  its frozen hash since `56ccc20`. It must not be re-frozen without a human-reviewed, versioned correction.
- **`frozen plans are read-only on disk` fails in a git clone.** A clone cannot store mode 444, and `CLAUDE.md`
  forbids chmod. It passes on a checkout where those files are 444.
- **Domain vocabulary.** The `softmax` operator symbol is part of the generic schema and renderer. Renaming it
  would change hash-locked fixtures, so it is documented instead.
- **Edge labels.** When no clear position exists, a label is flagged (`edge-label-overlap` warning) rather than
  the layout moving nodes.
